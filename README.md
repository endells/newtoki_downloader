# 북토끼 소설 다운 · 구주소 전용 v0.2.21

`newtoki_downloader_legacy`라는 독립 FF 플러그인입니다. 새 주소용 `newtoki_downloader`와 이름, 설정 DB, 다운로드 이력 DB, 로그, 알림 설정, 텔레그램 상태, CSRF 키, 템플릿을 분리했습니다. 기본 저장 폴더는 `downloads/newtoki_legacy`입니다. 기존 플러그인의 이력을 자동 복사하지 않습니다. 기존 TXT를 확인하려면 저장 경로를 지정하고 작품 분석/기존 파일 검사를 실행하세요.

현재 구주소를 먼저 사용하고, 주소 안내 사이트에서 구주소 후보만 확인합니다. 새 주소로 자동 전환하지 않습니다. 구주소에서도 사이트의 인증·이용 제한은 그대로 적용되며 자동으로 해제하지 않습니다. 사람 확인 화면은 작업을 대기시키고 주소 복사·확인 후 계속을 지원합니다.

## 설치

FF 컨테이너 터미널에서 **기존 FF 플러그인 폴더들이 있는 상위 폴더**로 이동한 뒤 실행합니다. 기존 `newtoki_downloader` 폴더에 덮어쓰지 마세요.

```bash
git clone --branch legacy --single-branch https://github.com/endells/newtoki_downloader.git newtoki_downloader_legacy
```

FF 재시작 후 플러그인 목록에서 **북토끼 소설 다운 · 구주소**를 확인하세요. 구주소 버전의 연결/도메인, 저장 경로와 알림 설정을 별도로 저장합니다. 전용 브라우저 연결 주소는 기존 브라우저 주소를 사용할 수 있습니다. 이 브랜치는 `legacy`를 계속 추적하므로 이 폴더에서 `git pull`로 업데이트할 수 있습니다.

기존 파일 검사, 폴더 선택, 번호 정리, EPUB 재생성, 회차 번호 기반 중복 검사, 수집 간 휴식, 한국 시간 알림을 포함합니다.
