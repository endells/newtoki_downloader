사이트 / 브라우저 연결 · 도메인 갱신

이 사이트는 본문을 브라우저에서 별도로 표시합니다. 먼저 README의 전용 브라우저를 설치하세요. 보안 확인은 그 브라우저에서 직접 처리하며, 로그인·포인트 구매 버튼은 자동으로 누르지 않습니다.

동일 Docker 네트워크: http://newtoki-browser:9223
안내 사이트 주소는 변경 후 연결 / 도메인 설정 저장을 눌러 적용하세요. 안내된 구버전 → 현재 저장 주소 → 신버전 순으로 작품 목록을 확인합니다. 정상 목록과 기존 작품 제목이 확인된 주소만 적용합니다. 신버전의 사람 확인은 전용 브라우저에서 직접 처리하며 모든 후보 실패 시 기존 주소를 유지합니다.
이 영역은 기본 설정과 별도로 저장합니다. 저장만으로 접속 확인이나 다운로드를 시작하지 않습니다.

텔레그램 채널 → 자동 수집 목록

① BotFather에서 전용 봇 생성 → ② 수신할 채널에 봇을 관리자로 추가 → ③ 토큰과 채널 ID 저장 → ④ 새 작품 링크 게시. 일반 메시지·캡션·숨겨진 링크에서 구버전 작품 번호를 추출하며 중복 등록하지 않습니다. 기존 게시물을 일괄 탐색하지 않습니다. 다른 프로그램과 같은 봇을 공유하지 마세요. 수신은 목록만 추가하며 다운로드 예약은 기본 설정에서 별도로 켭니다.
